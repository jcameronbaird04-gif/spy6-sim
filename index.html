Reading the picture

Blue cones
Radar dwells. Each flash is one look from the array face that covers that bearing. SPY-6 updates every track four times a second; SPY-1D's single beam per face takes turns between search and tracks.
Yellow
Unknown track, newly detected.
Red
Identified hostile.
Blue
Own interceptor: SM-2 for drones and cruise missiles, SM-6 for the anti-ship ballistic missile, SM-3 for the missile in space. Drone 4 gets the 5-inch/62 gun (airbursts), and the late pop-up Drone 5 gets the Phalanx CIWS.
Air picture
Navy track symbols: yellow square top = unknown, red diamond top = hostile, blue half circle = own missile, green X = destroyed. The dashed blue ring is detection range for a 0.1 m² target. Symbols move only when the radar updates them, so slower updates show up as jumps.

Illustrative model for a PHYS 271 project, from open sources. Real distances, altitudes and speeds: Shahed-type drone 185 km/h (Army Recognition), SM-2 and SM-6 above Mach 3 (RAN), SM-3 about 3 km/s (Wikipedia). Radar ranges, target sizes and dwell times are made-up round numbers; only the 2.37× range ratio between radars comes from the published +15 dB. Playback 1× is 8× real time. Small objects are drawn larger when far away so they stay visible. Not real tactics or performance.
