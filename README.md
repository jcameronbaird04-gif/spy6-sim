# SPY-6 vs SPY-1: Flight III Kill Chain Simulation

Interactive 3D simulation for a PHYS 271 project at the University of San Diego.
A Flight III destroyer defends against a Red Sea style raid (drones, cruise missiles,
an anti-ship ballistic missile and a ballistic missile in space). Switch the radar
between SPY-6 and SPY-1D to compare.

**Open the simulation:** the GitHub Pages link for this repository.

Built from open sources only. Radar ranges, target sizes and timings are illustrative;
only the 2.4x range ratio comes from the published +15 dB sensitivity figure.
